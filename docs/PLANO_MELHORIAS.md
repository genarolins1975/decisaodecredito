## 3. Como verificar

```bash
cd aula_credito_html
node build.mjs                                   # três saídas, versão, conferência das notas
node qa.mjs --estados                            # 1366x768; repetir com --largura 1920x1080, 1024x768, 390x844
node qa.mjs --aluno --estados                    # variante do aluno
node lint-tracos.mjs
node material.mjs                                # guias em PDF (professor e aluno) em dist/material e content/materiais
cd ..
npm run typecheck && npm run lint && npm test    # inclui tests/aula-2-build.test.ts
npm run test:e2e                                 # exige servidor e banco; "aula em slides" e "moldura da plataforma" cobrem a Aula 2
npx vitest run tests/aula-2-plataforma.test.ts   # sequência do curso com a Aula 2 entre os capítulos 3 e 4
npm run lint:tracos                              # hífen e travessão de prosa nas cascas React

# páginas da Aula 2 renderizadas pela plataforma (exige servidor e banco)
node qa-plataforma/varre.mjs --estados                       # estudo, 1366x768
node qa-plataforma/varre.mjs --rota apresentacao --estados   # projeção
#   repetir com --largura 1920x1080, 1024x768, 390x844; --fotos guarda a captura de quem falha
```

Depois de qualquer alteração em `aula_credito_html/app/`, recompilar antes de testar: a plataforma e a QA leem as saídas, não os fontes.
